The An-24 livery patch is a set of modified files for the FlightGear Antonov An-24b. Its purpose is to enable the livery selection menu on the An-24.

To install this patch:
- Install the An-24 (this patch is based on the 2018 version, but might work with other versions as well);
- Make a backup of $FGHOME/Aircraft/an24b (the whole directory);
- Unzip An24_LiveryPatch.tar.gz into $FGHOME/Aircraft/an24b , "overwrite existing files" must be enabled;
- Install one or more add-on liveries into $FGHOME/Aircraft/an24b/Models/Liveries
- Start FG and check that the "An-24/select livery" works. If it dosen't, you can go to the FGFS forum (forum.flightgear.org) and search for "An24 livery patch". (No link yet, because this file needs to be uploaded before the discussion is started, otherwise there would be nothing to discuss...)
