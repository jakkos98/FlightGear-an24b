This is apaintkit for the FlightGear Antonov An-24. Its purpose is to make it easier to include, when drawing additional liveries, the items that never change such as rivets, windows, underside shadows, hinges...
How to use: Open the _background.png file in your favorite image editor (e.g. GIMP, Inkscape...), draw the livery above it (without transparency), then import the corresponding _overlay.png and add it on top of your livery, then render/export the whole drawing in PNG format. Saving your livery layer as a standalone file will help you if you want to modify it later.

To get the livery selection menu, you can install the An24 livery patch (available at https://drive.proton.me/urls/1ZC5FFRYZM#KkyQRFGK7Ei6 ).
